# OnLive Expo – demo bundle

- Open `index.html` (double-click) or upload the whole folder to Netlify / Cloudflare Pages / GitHub Pages.
- `evaluation.html` / `evaluation.md` – business review, cheaper plan, anchor-partner pitch.
- GSAP loads from cdnjs. If it is blocked, `js/gsap-fallback.js` keeps everything animated.
- All companies are fictional. Data is saved only in the visitor's browser.
- Edit companies and prices in `js/data.js`.
